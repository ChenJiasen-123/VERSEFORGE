# 本轮评价局限（训练阶段记录）

evolution-01标准在运行中保持不变，不用这些发现重评择优或窥看留出题后改策略。

1. 盲读gap字段有时包含“虽有歧义但不影响成立”的说明。当前按非空判缺口，会误扣分；decision与gap也可能不一致。
2. device_risks数量是模型列举习惯的代理，不能当文学质量分。当前只在题意、格律等优先条件同等时排序，仍可能引入偏差。
3. unknown读音很多；没有明确冲突不等于合律，不能把当前作品对外称为格律达标。
4. 原稿与改稿采用序数规则，尚无每轮文学双向比较。最后留出对照必须另作匿名正反序比较，不能以内部筛选自证有效。
5. 失败用量在传输抛错后不可得，ledger少算这部分。费用不能由成功token总数直接认证。
6. 正式运行只绑定实验源码、题集和知识文件；导入依赖没有整体版本绑定。source-snapshot仅证明实验源码与启动绑定一致，不是完整环境重现包。

上述问题应进入最终报告；是否重做须在本轮留出评测前明确设计新的独立实验，不能悄悄替换本轮结果。

## 初始种群与首代变异观察

generation-0中g0-1排名第一主要因无调用失败，其余两份各有两题失败。当前排序把每个失败赋大惩罚，因此初始排名主要反映可用性，不能解释为文学水平高低。三份均有大量unknown，不能称形式合律。

pending-1中g1-1提出避免用典、只停可感表面，g1-0偏好动作结尾。此类变异可能重新制造安全与单一性，须依最终作品检验，不将自然语言策略更长或更具体视作进步。

执行器对已有成功结果复用，对只有failure文件的父代题会在下一代重试；这使父代失败题存在额外尝试机会。原失败文件可能与后来的成功文件并存，统计必须按候选-题目识别终态并保留历史失败，不能简单glob计数。该行为属于本轮实验混杂，不隐瞒或用重试成功擦除失败历史。

## 第三代变异的约束漂移

pending-3中g3-2把训练题的局部禁词扩展为所有作品禁用借、还、愁、忆，并强制微动作重复、禁止反问与部分拟人。这与“不预设全局情绪/修辞禁令”的研究意图存在偏离。当前变异模块只检验strategy为非空字符串，没有独立的策略语义有效性门槛，故该子代仍被本轮执行器评估。最终必须将此视为方法缺陷，不能把适应度提升直接当作实现了用户要求的修辞多样性；不得因已看部分结果而暗中删除该子代重排实验。
