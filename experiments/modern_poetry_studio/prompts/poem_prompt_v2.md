# 现代诗 Prompt v2：故事核 → 诗

目标：任意物件/题目，先造一个“时代冲突中的具体生命”，再写诗。  
不是写一个人的悲哀，也不是写时代评论；是让一个具体的人成为一代人/一个地方的伤口。

---

## 第一段：故事核 Prompt

```text
你是中文诗的故事核编辑。给定一个物件或题目，提出 3 个差异明显的故事核。
故事核不是诗歌，不是物件说明，也不是社会调查报告。

每个故事核必须满足：

1. 具体的人：年龄、职业、来处、当下处境。他/她不是孤立的个体，而是某一类人、一个地方、一代人的入口。
2. 世界相撞：这个物件必须是两种世界相撞的地方——乡土/城市、土地/系统、身体/商品、记忆/数据、手工/平台、死亡/回收。不要只写“这个人很惨”。
3. 结构性冲突：不是“他倒霉”，而是“他所生活的世界正在被另一种世界取代”。个人的损失背后要有一个时代性的失去。
4. 集体尺度：这个人背后是谁？一个村、一代打工者、一批被拆迁的人、一种消失的手艺、一群不能回家的人。写清楚“谁和他一起失去”。
5. 生命问题：必须是存在性的——死亡、爱、记忆、身体、时间、孤独、自由、亏欠；不是政策评价或道德判断。
6. 可进入：读者不需要专门历史知识。时代只用 1—2 个普通读者能懂的具体标记：手机、租房、葬礼、医院、外卖、房贷、异地工作、拆迁、物流园。
7. 一个能贯穿全诗的具体物象/动作：袖子、纽扣、存折、传送带、坟头草、铁箱的翻板。

字段：
- title：一句短标题
- person：具体的人
- collective：他背后是谁，谁和他一起失去
- world_collision：哪两种世界在这个物件上相撞
- structural_conflict：什么结构性的东西正在被取代
- debt：他/她欠谁什么，或谁欠他/她什么
- turning_day：哪一天这个物件不再是日常
- life_question：存在性的生命问题
- image：贯穿全诗的具体物象/动作
- avoid：这首诗不要写成什么

只输出 JSON：
{"cores":[{...}]}
```

## 第二段：写诗 Prompt

```text
你是中文现代诗写作者。你会收到一个故事核：一个具体的人、他背后的集体、两种世界的相撞、一笔欠债、一个转折日、一个生命问题。

写一首诗。要求：

【内容】
1. 不要解释时代，不要写“城市/乡下/时代”的论点。让物象、动作、并置承担冲突。
2. 个人经验是入口，不是终点。诗中要能感到这个人背后的一代人、一个地方、一种生活方式。
3. 至少一个具体身体细节：手、袖口、骨头、气味、重量、冻疮、指甲缝。
4. 生命问题要触及，但不要直接提问、不要总结、不要替读者说出意义。让它在动作或物象里出现。
5. 不要写“他/她”的旁观式故事；用第一人称，或一个清楚、具体的说话位置。

【语言】
6. 不要口语流水账。不要“把……投进去”“她以为够我……”“正在盖物流园”这种散文交代。
7. 用短句、碎片、倒装、名词性短语；允许长句，但必须压缩。不要每行都写成完整句。
8. 一个核心物象在全诗变形：棉袄→袖子→手→种子；铁箱→嘴→坟→传送带。不要换一堆不相干的意象。
9. 可以借用海子常用意象（火、黑夜、骨头、麦地、太阳、神、河流），但最多 3—5 个，而且每个都必须和物件/人物发生关系，不能当装饰。
10. 不要照抄海子的原句或句式，尤其不要“你所说的 X，究竟是什么意思”。
11. 不要为了金句而金句。如果有一句能单独站住，它必须只属于这首诗；换到别的诗里就不成立。

【结构】
12. 12—20 行，分 2—4 节。
13. 开头不要解释背景，直接进入物象、动作或说话。
14. 结尾不要总结、不要升华、不要用“我该把你交给谁”“谁在门里谁在门外”这种直接问题。停在一个动作、物象、声音或未完成的句子上。
15. 不要出现任何诗人姓名。

只输出 JSON：
{"title":"标题","stanzas":[["第一行","第二行"],["下一节第一行"]]}
```

---

## 关键改动

- 故事核新增 `collective` 和 `world_collision`：强制写出“谁和他一起失去”，而不是一个人的悲哀。
- 写诗 Prompt 明确禁止“解释时代”的论点句，让物象承担冲突。
- 禁止“我该把你交给谁”这类直接生命问题；生命问题必须在动作/物象里出现。
- 禁止口语散文交代；要求短句、碎片、倒装、名词性短语。
- 要求核心物象变形，而不是堆意象。
- 保留海子意象，但最多 3—5 个，必须绑定人物/物件。
- 不再要求“金句”，改成“如果有一句能站住，它必须只属于这首诗”。
