总体说明：先落实可观察的动作与场景，再让情感从场景缝隙中渗出；不直接命名情绪，用可触摸的具体物象与有限复现的短句承载抒情。

1. 每节3—5行，且至少一节为3行、一节为5行，形成长短节交错；每节末行行尾落在具体名词、短促动作或数量词上，不得为“的”字结构或抽象形容词，若出现须改写为具体名词或短促动作。
2. 设置一个反复出现的短句或半句（不超过8字），全诗复现不超过两次；第二次复现必须改变句法位置（主语变宾语或反之）或替换其中一个修饰语，二者择一即可，不得原样重复。
3. 开头两行只写可观察的动作或场景（走、埋、升起、收割、站立、吹过），不出现“爱”“悲伤”“孤独”等情绪词；全诗情绪词不超过两处。
4. 全诗至少有一行达到15字以上且该行无主语，至少有一行达到15字以上且谓语前置（倒装）；其余行以主谓宾短句为主。不用连续三个以上“的”字定语。
5. 意象从土地、天体、草木、鸟兽四类中至少选两类，每类选1—2个具体物象；器物类具体名词全诗不超过两个，且不得连续两行出现器物名词。
6. 用“一……一……”或“从……到……”的对举结构制造空间张力，全诗不超过两处；对举两端须一具体一虚化。
7. 情感推进路径：先写外部场景的物理状态（如退水、停摆、空置、倾斜），中段插入一个第一人称的动作（我走、我看、我抱、我归还），末段让情感凝结在一个反复句、一个未完成的疑问或一个名词性短语上，三者择一；不得是总结性判断句，不得用感叹号。
8. 全诗问句不超过三处且集中在后半；末行不写总结性判断句，不写感叹号。
9. 控制人称：第一人称“我”出现不超过五次，避免“我们”作抒情主体；全诗至少使用一处第二人称“你”的直接呼告。
10. 全诗不得连续使用“我数……”式计数动作超过一次；同一核心动词不得在收束句与开头两行中重复出现。
11. 全诗8—20行，不分小标题；段落之间用空行分隔，每段行数不平均，形成长短段交错。

## 10. 事实边界、已实现与待验证

**已经实现：** 参考语料选择、初始种群、生成、确定性指标、匿名 LLM 评审、差异分析、LLM 变异、父代+子代选择、断点续跑、缓存、预算上限、A/B/C 对照、报告与 Prompt 独立输出。

**已经验证：** 代码在 Mock 客户端下可完成全流程；单元测试覆盖选择、指标、提示词规则、缓存/预算、生成隔离、评审匿名和对照分组。真实 API 的生成质量与风格效果未在本仓库中验证。

**仍待验证：** 适应度权重是否合理；确定性指标与人类风格判断的相关性；LLM 评审的稳定性与自评偏差；不同模型家族评审的一致性；参数（n、m、k、题目数）对结果的影响；真实付费运行的成本与收益。

本实验寻找的是“具有相似风格控制效果的 Prompt”，**不是**恢复诗人的真实创作指令。高 ROUGE-1 只说明文本重合，不等于风格模仿成功；报告不据此下结论。

## 11. 与论文方法的差异

详见 `METHOD_ADAPTATION.md`。核心差异：ROUGE-1 改为诗歌领域多维适应度；增加题意、原创性、文学质量约束；评审器匿名且不接收候选 Prompt；生成器不接收参考作品；保留 mean/max 思想但以多题均值为主；无交叉；加入缓存、预算、断点续跑和人工可审计记录。
