## 10. 事实边界与方法说明

**运行性质：** 本次为真实 DeepSeek API 运行（生成模型 `deepseek-flash`，匿名评审模型 `deepseek-chat`），全部记录可由 `ledger.jsonl` 与 `cache.jsonl` 审计。

本实验寻找的是“在新题目下具有稳定可迁移风格控制效果的精炼 Prompt”，**不是**恢复诗人的真实创作指令。高 ROUGE-1 只说明字面重合，不参与风格主分；审美判断仍建议结合人工盲读核查。

### 本次运行特定限制

- 评审模型（deepseek-chat）与生成模型（deepseek-flash）不同，但仍属同一供应商家族，建议结合离线统计与人工盲评。
