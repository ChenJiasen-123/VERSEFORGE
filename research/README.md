## 阅读证据标准

每篇记录：作者、作品名、版本与译者、文本来源、访问日期、实际阅读范围、声音结构、句法与分行、意象关系、情绪推进、结尾、可迁移原则、易误用处、证据级别。

原作细读、作者或编者说明、学术分析、活动报道分开。活动报道仅能证明作者身份、书目线索或本人发言，不能替代作品细读。原诗与中文译诗不能混同：金子美铃的日语音数与中文译本节奏分别记录。

不批量复制受保护诗集。公开研究记录以原创分析、书目信息和少量必要短引为主；未经权利确认的阅读材料不进入训练集。

## 现代诗暂定评价维度（待细读修正）

1. 声音组织：停顿、延长与语义悬置分别观察；重复是推进意义还是维持必要的压力；押韵是否自然而非倒装凑韵。
2. 分行必要性：行尾是否产生延宕、强调或歧义；合并成散文后是否丢失结构。
3. 意象关系：意象之间有可感知联系，不按“月光、远方、灵魂”清单堆叠。
4. 情绪运动：情感与处境、动作和说话姿态的关系；允许持续、不解决，不强求转折。
5. 结构与结尾：结尾怎样承接、改变或完成前文；具体收束不天然高于明确陈述。
6. 可朗诵性：真实朗读中重音、停顿、重复与换气可成立；文本代理指标不能直接证明音韵美。

上述为研究假设，不作为五位作者共有特征的既成结论。
