# 第二组停顿样音：去除内部逗号叠加

2026-11-18。实际生成三段本机中文语音，采用同一原创短句，去掉内部逗号、保留共同句号。原始输入、停顿请求、声音参数、文件时长及摘要见[manifest](manifest.json)。未播放到扬声器，未实际听评，未接机器人。

- [无显式停顿](continuous.wav)：TTS仍可自行组织韵律，不等于没有停顿。
- [物件／处所之后](object_boundary.wav)：两次400ms请求。
- [修饰语／动词之后](syntactic_suspension.wav)：同样两次400ms请求。

两种有显式停顿的输入只改变break的位置，汉字、标点、声音参数及break数量和请求时长一致。与第一组不同，这次没有break紧邻内部逗号的条件。但不因此声称已经隔离所有声学变量：引擎可能随分段改变读音时长、重音及默认停顿，也不能把总时差直接当break时长。

去掉逗号本身也改变了默认韵律条件，所以新旧两组不能混算为同一次比较。输入一致、波形有效与美感成立分别记录；当前没有优胜样音。

研究问题是：暂停是否延迟了某个尚未完成的句法关系，听者能否保留这种等待，或反而误解对象。不能只按哪段更顺判断，也不能预先宣告句法悬置必然更有诗意。后续试听可允许无差异、均不自然或依语境改变选择。
