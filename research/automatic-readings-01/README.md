# 来源受限的自动核音01

实现automatic_readings：提供三个已核来源义项（中作内部、犹作仍然、暖作温热），模型只按正文选择卡片ID，程序映射历史平仄和韵部。选择请求不包含目标谱、期望平仄或韵部标签，不许编造ID、错字位、重复字位。生成记录绑定正文哈希后交现有apply_review。

真实API为先前同一七绝修订稿选择语境卡，所选基本谱检查pass；模型自己未见目标谱。此为一个已见样本的自动执行证据，不是泛化准确率或模型语义选择已获独立验证。context_choice_verified=false保留。219项测试通过。

不覆盖卡片之外的义项，不能把仅有的卡片当作该字唯一读法；模型应无匹配时留空。未自动并入网页，也未认证整个作品的文学水平。下一步须以中作命中、犹非仍然义等反例验证弃权，再考虑接入编辑流程。原始实测JSON的source为早期单个义音链接，代码随后补记历史韵部来源；不得把后改来源说成旧响应原本包含。
