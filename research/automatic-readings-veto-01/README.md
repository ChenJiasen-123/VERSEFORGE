# 已知词义冲突否决01

新增只否决、不改选读音的词义冲突规则。中条辞书的获奖、感染、考取、命中等动词义不等于方位内部义；犹如的类比不等于尚且。中箭、中流矢等为项目据命中动词义作的有限上下文匹配，不声称辞书逐条列出这些完整诗句。

依次回放negative-02四份不变的实际模型响应，hit、win、like均从自动选择改为记录veto并弃权，inside正例仍选择。没有新增API调用，也不证明模型已学会弃权。221项测试通过，增加中毒、中举等未在四次实测里的词组回归。

未命中规则并不证明字义正确；短串规则也不支持任意古汉语切分。当前仍是实验模块，不接入网页过谱判定；须继续做异义词与跨句词组等反例，不能把词组表替代完整语境理解。不能因程序成功否决反例就声称自动核音已可靠。
