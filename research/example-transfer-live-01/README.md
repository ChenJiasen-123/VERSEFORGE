# 正面片段完整运行与模板迁移风险

真实在家练获奖感言题，12行以内，无人工中间选择。最终《彩排》12行，独立编辑2次调用后keep，但题意confirmed=false，不能称合格定稿。程序检测未见示例的连续8字片段照搬；这只是字面检查，不能证明结构原创。

输出“举到第三遍／才发现”与未说完半句落成物件的组织方式，分别接近用户原先肯定过的两种片段结构。即使道具已换，组合出现仍提示模板迁移风险。这是助手观察，不能据此断言作品侵权或完全没有原创性。

据此新增compose的example_relations_only开关，网页使用关系分析，不再把原片段、数字和动作链直接给生成模型。哈希校验与原始反馈存档不变，元数据记exposure。分析原则由助手从已记录用户反馈归纳，非用户逐字规则，也非参数训练。226项既有测试通过；新方式尚未真实复测或重启到本地服务。
