# 审美阶段：目标与证据核对

当前执行以用户后续选择为准：将已有审美落实到Agent，边做边研究；暂无GPU，继续文本与Agent；朗读不属于当前阶段。以下按现有运行与源码修订，早期纯阅读阶段的状态不再作为当前能力结论。

## 现在形成了什么

审美基础正在形成，核心不是收集漂亮词语，而是解释一首作品为何需要这样的说话方式、声音和结构。判断必须能落到具体文本，也必须允许反例。

| 当前判断 | 细读形成的依据 | 使用边界 |
|---|---|---|
| 先看作品要完成何种经验，再判断语言是否合适 | 金子美铃的视角转换、海子的象征与公共声音、席慕蓉的回望、徐志摩的口语和声势、林徽因的观察与思辨呈现不同需要 | 不将这些概括当作作者全部作品的固定风格 |
| 意象的价值在关系与运动中 | 一个物件怎样被触碰、看见、留下或重新理解，比孤立的“美丽意象”更能解释文本作用 | 抽象表达、象征和直接抒情也可能成立，不能统一删掉 |
| 重复、分行与停顿必须结合语义判断 | 同词复现可以改变处境；跨行可以悬置，也可能只是割裂句法 | 次数、行长和停顿时长不能直接换算美感分数 |
| 叙述者的目光本身需要审查 | 《窗子以外》等提醒：看见他人的生活，不等于理解他人 | 自我怀疑也不自动产生深刻，需要看文本是否真正改变了认识 |
| 结尾需要回应全篇的运动 | 邀请、直陈、余留、反问和未解决的持续均有成立实例 | 不规定每首都反转、升华或以具体物象结束 |
| 古典规范与现代声音要分开处理 | 入声与普通话声调不同；同一词牌可有多种体式；现代诗也有自己的声音组织 | 字数正确不等于格律合格；普通话押韵不等于符合指定韵书 |

这些是可修正的阅读判断，不是已经验证的自动评价器。具体依据与反例见[文学判断准则](aesthetic-criteria-v0.2.md)及各篇阅读笔记。

## 原目标目前到哪里

| 目标 | 已有证据 | 仍缺什么 |
|---|---|---|
| 全面且详细学习五位作者，建立审美 | 有来源记录、逐篇分析、跨作品比较、版本疑点与原创改稿 | 作者阶段与题材覆盖仍不均衡；部分转录未经原刊或印本核对；不能称完成全集研究 |
| 现代诗具有音韵美 | 已有真实API同题工作流对照、文本声音审读与分行差异定位；四组八首匿名文本已核对原记录并导出 | 四组配对尚无用户文本偏好反馈；没有独立质量提升证据。纸面语音组织可先评阅，朗读按用户要求不推进 |
| 古诗词符合格律 | 五绝、七绝各四种指定基本谱及网页平水主表检查已实现，修订传递具体反馈；《雨後春江》作品集稿有独立正文绑定的助手核音通过记录；词实现一种忆江南谱体的字数和平仄核对 | 不覆盖所有诗体、词牌、合法变格及完整词韵；多音和异体仍需有依据的语境复核。个案通过不等于任意题目稳定合律 |
| 持续改进 Agent 并微调 | 提示、审读、改稿、多候选、分行与格律反馈已有实现和真实调用记录，源码与材料已上传私有VERSEFORGE仓库 | 参数训练未实施，用户选择先文本与Agent；训练准备材料不能代替已训练模型，也没有独立文学优胜结论 |

## 研究与程序的明确分界

`poetry_agent/core.py` 的硬检查覆盖格式、关键词及指定谱体与现有资料中的明确冲突。未决读音不冒充通过，也不强制为消除unknown而换字。候选先满足已实现的硬要求，再可由模型比较文学取舍；模型自评不能证明真正优胜。`review_meter.py` 及 `context_review.py` 支持精确正文与具体字位绑定的核音记录。完整范围和使用方法见项目README，不能由单项测试通过推及全部诗词。

下一步优先取得会改变改稿决策的文本反馈，并补不同版本、题材和结构的反例。当前已有[匿名文本评阅稿](text-review-01/review.md)，不展示生成方法与模型自评；曾看过作品仍可能影响匿名性，故不称严格盲评。真实反馈到来后需按样本与原文记录，不预填胜负或训练标签。

## 审美基础的阶段性核对

本表核对的是研究成果是否实际形成，不是五位作者研究或全目标的完成验收。没有另设用户审批要求，也不以本表取代用户对后续侧重点的选择。

| 能做出的判断 | 现有可检查材料 | 证据边界 |
|---|---|---|
| 说明具体作品的组织与效果，而非只贴风格标签 | 细读01—37、古典细读01—10，逐篇入口见阅读目录 | 分析深度不一，部分底本尚未核验；助手解释可受质疑 |
| 比较相同手法在不同作品中的作用 | 重复对读、诗论对读、五位作者审美档案 | 不是统计验证的普遍规律 |
| 将判断用于实际改稿并交代取舍 | 原创改稿练习中的等待、厂房、月影、借伞；直接表达练习 | 助手同时创作与自评，不是人类偏好或项目模型质量对照 |
| 区分正面追求与禁止清单 | 审美基础的五项作品品质、六类改稿路径及反例 | 不能由清单自动得到文学分数 |
| 区分诗、口头邀请和澄清答问的需要 | 同场景三种表达练习 | 没有现场理解率或机器人验证 |
| 提出声音假设并把它与实际效果分开 | 两组合成样音、输入与文件核查、现代诗朗读协议 | 六段文件存在不等于六次听评；没有独立听觉判断 |
| 将格律规范、传统读音和现代发音分层 | 声调谱、词谱研究，七绝规则核对与《雨後春江》逐版语境复核 | 已有指定基本谱个案通过；完整诗词范围、统一底本和独立专家审校未完成 |

由此可以说：已经形成一套有具体文本支点、能用于试改且允许反证的初步审美基础。不能说全面掌握五位作者、建立公认评价标准、验证现代诗音韵美，或完成参数微调。后一组要求仍属于原目标，未被缩减或替换。

下一次独立研究应优先补能改变判断的证据：印本差异影响语义时核底本；取得具体文本偏好与反例；早期笔记只有一句概括时深化全篇。旧音频记录仅作历史证据，当前不追听觉任务。重复整理同一原则本身不算新的文学证据。
