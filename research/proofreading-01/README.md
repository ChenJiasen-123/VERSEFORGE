# 独立文字校对01

proofreading.py只查技术性文字问题，不评价意象或情绪，建议必须绑定行位与原文。真实同稿两模型都定位第二行残留半角冒号，窄任务比此前总审稿更直接发现该处。

但flash理由声称“全角与半角重复粘贴”，原行只有半角，解释有误；其建议又混入新的冒号，不能自动执行。pro提出删除或统一，也含两种方案，不能当作确定编辑脚本。程序引文校验通过不表示理由及建议已经证实。

229项测试通过。尚未接入正式编辑链路，需增加正常破折号、引语跨行等对照，且后续改稿仍应由模型在上下文中执行、重新校验，而不是按自然语言建议直接字符串替换。一次同稿定位不支持总体准确率或模型优劣结论。
