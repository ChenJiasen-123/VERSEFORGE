# 正常标点对照与多轮接入

两组助手自写正常跨行引语、冒号、破折号控制，flash与pro各审一次，四次均issues为空。样本少且非用户标签，不支持总体误报率结论，但未出现将这两种正常形式强制改整齐的情况。

现代诗多轮编辑已加入独立校对，建议进入模型改稿输入，不直接字符串替换。新稿重查题意与校对；仍有校对问题则不采用。若只有标点变化、题名相同、正文文字序列不变且复核通过，自动采用修复，不因文学比较偏好而返回明显残留符号。其他文字改动仍走文学复核和比较。总调用预算包含校对调用。

230项测试通过，包括无需人工选择的标点修复路径。完整真实校对整合运行和服务重启尚未执行。校对引文有效不保证理由准确，尤其前轮flash虚构重复标点的风险仍保留记录，不能以本轮四个空报告消除它。
