# 暖／煖覆盖诊断

已核本地平水韵主表摘录：上声十四旱含“煖”，当前查找却未给“暖”提供该候选。glyphs.py仅使用有固定哈希的OpenCC STCharacters简繁字典，不能视为完整异体字典。diagnostic.json保留暖、煖、中、犹、猶的当前查找结果，不改动原韵表。

外部复核：2026-11-24读取维基文库平水韵繁体页面 https://zh.wikisource.org/zh-hant/平水韻 。另搜索到搜韵十四旱字表标注“煖[同暖]”，但尚未完整读取该条及其字义说明，不能仅凭搜索摘要把双字等价作为所有语境的自动转换规则。词林正韵含暖也不能直接替代平水韵证据。

当前结论是查找覆盖不足，非该字不存在历史仄声依据。后续补充应作为有来源、可追查的异体候选层，保留原字与语义选择的不确定性，不改写原诗、不把候选自动当作语境已判定。中与犹的多部归属仍需另查，不随暖的补充一并消失。
