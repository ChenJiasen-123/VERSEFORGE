# 新题材声音对照01

两组助手自写诊断稿，无人类偏好标签，不作好坏金标准。第一组搬家同名邻居，改变末尾重复与概括；第二组打电话，比较不同标点、分行与句法压缩，不是仅改分行的严格控制实验。完整双序判断见两个JSON，复现脚本tmp/sound_contrast.py。

实际结果：两组均disagreement/tie。每组正序和反序均偏向呈现位置A，归回原稿编号后正好相反。理由分别能辩护动作回环与直接判断、分离应答与同声压缩。这是本次四次比较中的位置敏感现象，不足以推断模型普遍总选A，也不能认定两稿等优。

结论：不能把能解释文本声音等同于能稳定选优。继续保留双序不一致时不替稿的规则；新增position_pattern标记，让这种表面理由充分但随顺序变化的结果可追查。213项现有测试通过。该标记仅记录模式，不矫正选择，也不证明偏差的因果机制。

下一步应以候选在题意、全篇关系和声音上的具体所得与代价组织定向改稿；不能为了制造稳定选择而把稿间差异改成明显好坏，或反复比较直到想要的候选赢。
