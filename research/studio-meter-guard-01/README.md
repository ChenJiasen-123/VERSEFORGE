# 正式单次修订的格律退步门槛

studio.py在正式单次题意／基本错误修订后增加meter_revision_guard，用同一目标谱的逐项变化比较，拒绝新增错误、已通过位置丢失、错误变不确定，以及目标或字位不可比较。保留所有候选，最终报告仍重算当前稿。

本门槛不把unknown当错误；无新增退步不代表整体格律已通过。225项程序测试通过。replay.json以既有真实模型的题杯原稿与修订稿离线回放，非新生成；该样本的具体接受结果与逐项变化按JSON记录。

当前只修正已有正式单次修订的接受条件，尚未把古诗接入多轮文学编辑或来源受限自动核音。源代码改变尚未重启本地服务。下一步需在新格律失败样本上验证自动修复与停滞处理，不能仅有拒绝规则没有改善路径。
